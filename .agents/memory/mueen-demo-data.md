---
name: MUEEN demo data
description: Product context and data-integrity expectations for the MUEEN crowd-management dashboard.
---

MUEEN is the user's graduation project: a smart security assistant for crowd management and risk prediction around Al-Masjid al-Haram in Makkah. The dashboard currently uses illustrative crowd counts, density/risk levels, unit positions, and report examples; no live operations feed is connected.

**Why:** The user requested simulated, socket/API-like updates for the graduation demo.

**How to apply:** Keep simulation status visible in the UI and do not imply that crowd figures, alerts, map pins, GPS, or AI predictions are operational data.
